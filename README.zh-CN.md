# Remote Tab Download · 标签页下载

右键已经打开的文件标签页 → **下载到本地…**，即可把文件保存到本机。文件无需位于资源管理器已打开的工作区。

[English](README.md)

## 使用

1. 在桌面版 VS Code 或兼容编辑器中连接远程环境并打开文件。
2. 右键需要下载的文件标签页，选择 **下载到本地…**。
3. 在本机保存对话框中选择位置。

也可以从命令面板运行 **Remote Tab Download: 下载到本地…**，下载当前激活的文件标签页。

## 特性

- 支持工作区内外文件，不需要先复制到工作区。
- 优先下载右键的那个标签页，支持未激活的标签页。
- 按原始字节传输，适用于 XLSX、PDF、ZIP、图片、笔记本和文本文件。
- 支持具有文件 URI 的自定义编辑器，不依赖文本编辑器是否激活。
- 复用编辑器的 `vscode-remote:` 文件系统，兼容 SSH、WSL、Dev Containers 等远程连接，无需另配 SSH 凭据。
- 记住上次本机保存目录，支持取消和同名文件安全替换。
- 界面跟随编辑器语言，提供英文和简体中文。

## 安装

在插件市场搜索发布者 **robin211737** 的 **Remote Tab Download**，或从 [GitHub Releases](https://github.com/githubdbluo/vscode-remote-tab-download/releases) 下载 VSIX 后使用“从 VSIX 安装…”。

安装到**本地**即可，无需安装到 SSH 服务器。扩展在本机运行，以确保保存到本机磁盘。

## 行为和限制

- 下载磁盘上**已保存的版本**。检测到未保存修改时会提醒，需要最新内容请先保存。
- 首版会整文件读入内存，适用于文档和常规文件，不适合数 GB 的镜像。
- 正在执行的远程读取无法立即中断；取消会在读取完成后生效，不再覆盖目标文件。
- 每次下载一个文件，不支持文件夹、未命名文件、Diff 标签、终端或没有文件 URI 的 Webview。
- 本机文件也可通过标签页菜单另存一份副本。
- 不支持纯浏览器版 VS Code。

## 隐私

不包含遥测、统计、凭据收集、第三方运行时依赖或额外网络服务。通过编辑器现有远程文件系统读取，保存到你选定的本机路径。仅在编辑器扩展状态中保存上次使用的本机目录。

## 开发与验证

打包需要 Node.js 22+，运行支持 VS Code 1.74+。

```sh
npm ci
npm test
npm run package
```

已覆盖标签页选择、工作区外二进制文件、未保存修改、取消、读取失败和替换失败等自动化测试。
最终版本已在原版 VS Code 1.104.2 中实测本机二进制文件另存，并在 openUBMC Studio 1.135.0 中实测工作区外 SSH 文件到 Windows 的传输，SHA-256 一致。冒烟测试使用真实扩展 API 和文件系统，对保存及成功提示对话框作了替代；WSL、容器以及 macOS/Linux 本机尚未人工验证。
